# تشغيل بوابة يسير مجانًا — Firebase Spark

**الحل:** Firebase Authentication (Email/Password) + Cloud Firestore + GitHub Pages. **لا تحتاج Cloud Functions ولا خطة Blaze ولا بطاقة دفع.**

رابط النسخة الجديدة:
https://i-saeed7.github.io/yasir-learning-profile/grades/spark/

**الحالة:** الشيفرة منشورة في GitHub؛ التشغيل الفعلي لا يبدأ إلا بعد تفعيل الخدمة من Firebase Console ونشر قواعد الأمان واختبارها. لا تدخل بيانات طلاب حقيقية قبل الاعتماد الإداري.

## الإعداد الأولي — مرة واحدة

1. افتح [مشروع Firebase](https://console.firebase.google.com/project/yasir-learning-profile/overview)، وتأكد أن الخطة **Spark** وليست Blaze. من **Authentication → Sign-in method** فعّل **Email/Password**. ومن إعدادات Authentication → Authorized domains تحقّق أن `i-saeed7.github.io` مسموح إذا تطلبت طريقة المصادقة ذلك.
2. من **Firestore Database → Create database** أنشئ قاعدة البيانات الافتراضية (Standard/Native)، واختر موقع التخزين **وفق السياسة المعتمدة للجهة** قبل إنشائها. **لا تفترض أن مشروع Firebase القديم فارغ**: إذا كان يحتوي قاعدة تستخدمها خدمات أخرى، لا تستبدل قواعدها قبل مراجعة تأثير التعديل.
3. افتح [ملف قواعد Spark](./firestore.rules)؛ انسخ محتواه كاملًا إلى **Firestore Database → Rules → Publish** **فقط إذا كان المشروع مخصصًا لهذه البوابة أو أُقرت القواعد بعد مراجعة الخدمات الأخرى**. هذه القواعد تمنع جميع المسارات غير المسموح بها، لذلك قد تعطل تطبيقات أخرى إذا كانت تشارك قاعدة البيانات.
4. من **Authentication → Users → Add user** أنشئ حساب المنسق ببريدك وكلمة مرور قوية (احتفظ بهما لنفسك). انسخ قيمة **User UID** للحساب الذي أنشأته.
5. من **Firestore Database → Data → Start collection** أنشئ المجموعة `ys_admins` والمستند بمعرّف **UID** المنسق الذي نسخته. أنشئ الحقل `active` من النوع **boolean** بقيمة **true**. هذا التفويض يُنشأ مرة واحدة من Console، ولا يمكن لأي مستخدم منح نفسه صلاحية المنسق من صفحة الويب.
6. افتح [النسخة المجانية](https://i-saeed7.github.io/yasir-learning-profile/grades/spark/)، واختر «دخول منسق الموقع»، وسجل بالبريد وكلمة المرور. أنشئ طالبًا وهميًا ومجموعة فصول، وانسخ **رمز المجموعة** الذي سيظهر **مرة واحدة فقط**. اختبر الدخول في نافذة خاصة باستخدام مادة المجموعة ورمزها. جرّب الحفظ وتغيير الفترة والإغلاق والتصدير.

## ما الذي يعمل دون خادم مدفوع؟
- رموز منفصلة لكل مجموعة مادة وفصول، باستخدام حسابات Firebase Auth مستقلة تولدها لوحة المنسق.
- لا يتم تخزين الرمز السري في قاعدة البيانات؛ يشتق عنوان الدخول من المادة والرمز، وتتحقق Firebase Authentication من كلمة المرور.
- صلاحيات المعلمين مرتبطة بـUID المجموعة في قواعد Firestore؛ الطالب يظهر فقط داخل مسار مادته وفصله المسموح.
- حفظ الدرجات مباشرة في Firestore؛ إغلاق التقييم يمنع التعديل **بقواعد قاعدة البيانات** لا بمجرد تعطيل زر.
- إدارة الطلاب، الأرشفة، تعديل الإسناد، تعطيل رمز مجموعة، السجل الرقابي، والتصدير بصيغة CSV متوافقة مع Excel.
- لا توجد Cloud Functions، ولا تخزين درجات في Local Storage.

## اختبارات القبول الإلزامية
- اختبار الدخول باسم منسق فعلي + معلم بمجموعته ونافذة خاصة.
- فصول مختلفة للمادة نفسها لا تتداخل، ولا يستطيع مستخدم غير مصرح قراءة الدرجات.
- تُحفظ درجة تجريبية وتظهر بعد تحديث الصفحة ومن جهاز آخر.
- يمنع قفل الاختبار تعديله عبر الواجهة وبطلبات API.
- تعطيل المجموعة يمنع تعديل درجاتها القديمة، ويوقف عرض الطلاب في الواجهة.
- لا تستخدم بيانات الطلاب الحقيقية قبل موافقة الجهة التعليمية على معالجة وتخزين بياناتهم في النظام.

## ملاحظات دقيقة
- **إنشاء مجموعة جديدة:** يستخدم Firebase Authentication (بريد داخلي مشتق من رمز المجموعة + كلمة مرور قوية)؛ وجود خيار Email/Password ضرورة.
- **تغيير رمز المجموعة:** عطّل المجموعة القديمة وأنشئ مجموعة جديدة؛ لا يمكن استعادة رمز قديم لأنه لا يُحفظ.
- **تصدير Excel:** يُنتج ملف CSV بالعربية قابلًا للفتح بواسطة Excel، وليس XLSX أصليًا.
- **الحصة المجانية:** 1 GiB تخزين، 50,000 قراءة و20,000 كتابة يوميًا ضمن Firestore Spark؛ عند بلوغ حدّ Spark تتوقف الخدمة مؤقتًا بدل فرض رسوم تلقائية وفق الشروط الحالية.
- **تنظيمي:** النظام أداة داخلية غير رسمية، وليس بديلًا عن نظام نور.
