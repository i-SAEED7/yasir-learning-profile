# بوابة رصد درجات برنامج يسير التعليمي

الصفحة: [grades/index.html](./index.html)

## الحالة
نسخة واجهة تجريبية **ببيانات وهمية فقط**، أُضيفت إلى المستودع دون إزالة صفحة تحديد المستوى الأصلية. رابط الدخول من صفحة المستودع الرئيسية يفتح `grades/`.

## المواصفات المنفذة في الواجهة
- جوال أولًا، RTL، ولوحة ألوان المشروع البنفسجية/الزرقاء، مع الاستفادة من خط الوزارة الموجود سابقًا بالمستودع.
- المواد الدراسية الخمس عشرة والفصول 1/1 إلى 1/8.
- اختيار المادة ثم واجهة رمز الدخول (تجريبية فقط، لا تتحقق من رمز حقيقي).
- بطاقات الطلاب بالاسم الأول والأخير والفصل (أسماء وهمية).
- الفترات: فترة أولى، فترة ثانية، نهاية الفصل.
- تقويمية تحريرية، المهام الأدائية والمشاركة والتفاعل، «الكل» لعرض الدرَجتين دون جمع.
- تعديل الدرجات طالما الفترة مفتوحة، ولوحة تجريبية لفتح وإغلاق كل عنصر.
- تصدير CSV تجريبي قابل للفتح في Excel.

## تحذير قبل التشغيل الفعلي
**لا تستعمل هذه الصفحة لدرجات حقيقية.** الواجهة التجريبية لا توفر تحققًا أمنيًا أو حفظًا موثوقًا للبيانات. رمز الدخول غير موصول بخادم، وكل التغييرات مؤقتة في ذاكرة صفحة المتصفح.

## المرحلة المطلوبة للتشغيل الإنتاجي
- اعتماد حفظ البيانات لدى الجهة التعليمية المختصة.
- تهيئة Firebase Authentication/Functions وFirestore آمنة، وتفعيل قواعد المنع الافتراضي للوصول المباشر.
- إبقاء رموز الدخول في الخادم كقيم مشتقة من تجزئة مملحة، وتحديد عدد المحاولات وسجلات العمليات والمهلة الزمنية للجلسة.
- ربط الواجهة بـ API محمية تتحقق من صلاحيات المادة والمنسق عند **كل** عملية، وتمنع التعديل على درجات عنصر مغلق.
- تصدير ملف XLSX شامل مع فلاتر للمنسق فقط.
- تدقيق الترويسة والشعار ومراجعة الجوال قبل التشغيل الرسمي الداخلي.
- لا يُخزّن أي اسم طالب حقيقي أو درجة أو رمز سري في GitHub.
